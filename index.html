1. 노출 — 광고비가 실제 노출로 바뀌는 구조

비용 1원이라도 더 긁어오는 것은 점주의 몫. 대행사는 확보된 재원이 끊기지 않고, 막히지 않고, 낭비되지 않게 세팅해야 한다.
현재 네이버 월 광고재원 목표
900,000원
운영 핵심
Floor · Headroom · Cap

자동결제 시스템 — 핵심 질문

  • Floor: 비즈머니 부족으로 단 하루도 광고가 꺼지지 않도록 잔액기준 / 1회충전 / 일충전한도를 어떻게 잡아야 하는가?
  • Headroom: 주말이나 검색수요가 튀는 날 충전 리미트 때문에 추가 노출이 막히지 않는 구조인가?
  • Cap: 월 광고비 90만원은 넘지 않되 월초 잔액까지 포함해 실사용액을 어떻게 통제할 것인가?
  • 자동충전 한도와 실제 광고비 사용한도를 어떻게 분리해서 관리할 것인가?
  • 카드 한도 / 자동충전 실패 / 월말 잔액 부족 같은 운영 리스크를 어떤 안전장치로 막을 것인가?

현재 입찰 구조

광고그룹현재 기본 입찰가의도
장가_메인200원핵심 노출 확보
장가_중위100원중간 가격대 확장
장가_하위70원저가 노출 / 롱테일 확보

입찰가 공식 — 지금 꼭 답을 받아야 하는 지점

  • 지역·업종 평균 입찰가 대비 몇 %를 메인/중위/하위에 배치하는 것이 합리적인가?
  • 메인 200 / 중위 100 / 하위 70의 비율은 어떤 공식 또는 실무 경험에서 나온 것인가?
  • 입찰가가 올라갈수록 노출기회가 얼마나 증가하는지, 어느 구간부터는 CPC만 비싸지고 추가 노출이 거의 늘지 않는가?
  • CTR, 평균 CPC, 노출수, 실제 전환을 같이 봤을 때 “입찰가 최적점”을 어떤 지표 조합으로 판단할 것인가?
  • 메인/중위/하위 그룹이 서로 잠식하지 않고 각자 다른 가격대의 트래픽을 확보하고 있는가?
  • 장가_하위 70원이 현재 울산 북구 한식업종 평균 입찰가와 동일하거나 유사한데, 이 그룹은 어떤 노출 풀을 확보하기 위한 장치인가?
정리: STEP 1에서는 SEO를 다루지 않는다. 여기서는 순수하게 돈 → 광고송출 → 노출량의 구조만 본다. SEO와 플랫폼 페이지 최적화는 STEP 3 ‘몰입’에서 다룬다.

2. 호기심 유발 — 노출된 사람을 클릭시키는 힘

  • 대표사진 / 광고소재 1·2·3 순서를 어떤 논리로 설계해야 하는가?
  • 오션뷰 + 12계단 / 활어 액션 / 해물탕 액션 중 어떤 소재가 CTR을 가장 높이는가?
  • “12계단 한우&제철회 풀코쓰!”처럼 구체적 숫자와 강한 단어가 실제 CTR 상승으로 이어지는가?
  • 평범한 카피와 개성 강한 카피를 같은 기간 A/B 테스트할 수 있는가?
  • 소재 피로도와 CTR 하락을 어떤 기간 단위로 판단하고 교체해야 하는가?

3. 몰입 — 랜딩페이지 개선 + 플랫폼 SEO 최적화

광고를 눌러 들어온 뒤부터는 “플레이스 자체가 홈페이지”다. SEO 세팅과 랜딩페이지 개선은 같은 단계에서 본다.
해결된 질문 01 — 영문 업체명 90자 지면을 SEO 키워드로 활용할 수 있는가?
업체정보 수정 → 기본정보 → 사업자 정보 → 영문 업체명
해결완료
질문: ‘해우 울산점’을 영문으로 입력할 때 Haewoo Ulsan만 쓰는 대신, Ulsan / Buk-gu / Gangdong 같은 지역 키워드를 90자 안에 최대한 채우는 것이 네이버 SEO 노출에 유의미한가?

결론: SEO 용도로는 아무짝에도 쓸모없는 지면. 이 칸은 검색 키워드를 확장하는 공간이 아니라 국문 업체명을 영어로 정확히 옮겨 적는 용도로 보면 된다. 따라서 Gangdong, Buk-gu 같은 지역 키워드를 추가해 90자를 최대한 채우려는 시도는 무의미하다.

정답: ‘해우 울산점’의 자연스러운 영문 상호만 기입.
하지 않을 것: Haewoo Gangdong Ulsan Branch / Haewoo Gangdong Buk-gu Ulsan Branch 등 SEO 목적 지역명 추가.

대표키워드 A/B/C/D/E 로직

현재 대표키워드는 최대 15자 × 5개. 총 75자의 매우 제한된 지면으로 본다.

A메뉴/음식
초밥, 회, 해물탕 등
B재료/품질
활어, 제철회, 한우 등
C매장 특징
오션뷰, 바다전망 등
D이용 상황
가족외식, 회식, 생일 등
E지역/지리
울산, 북구, 강동 등

대표키워드에서 답을 받아야 할 핵심

  • 네이버 공식 입력란에는 “단어 하나씩” 넣으라고 되어 있는데, 실제 운영에서는 15자를 꽉 채운 문장 비슷한 조합형 키워드가 아직도 유효한가?
  • 조합형 키워드를 쓰는 이유가 실제 사측 데이터에서 확인된 것인지, 과거의 경험칙인지?
  • 15자 안에 여러 단어를 붙였을 때 네이버가 각각을 독립 토큰으로 인식하는가, 인접 단어 조합으로도 인식하는가?
  • 대표키워드 75자 안에서 A/B/C/D/E를 몇 %씩 배분하는 게 좋은가?
  • 연관 키워드 중에서는 검색량이 높은 단어를 우선해야 하는가? 예: ‘초밥’ vs ‘스시’.
  • 검색량이 거의 없는 세부 지역명 ‘당사동’을 넣는 것은 낭비인가, 로컬 연관성 때문에 의미가 있는가?
  • 지역명은 플레이스 주소정보에 이미 존재하는데 대표키워드에 또 넣는 것이 실제 노출에 도움이 되는가?
  • 공식 가이드와 실전 데이터가 충돌할 때 무엇을 기준으로 판단하고, 어떤 테스트로 검증할 것인가?

상세설명 2,000자 — 후킹 / 정보밀도 / 남는 글자지면

부분 해결 — ‘더보기 아래를 키워드 문장 더미로 꽉 채우는 방식’
상세설명 최대 2,000자
부분 해결
기존 로직: 더보기 전 = 후킹 / 더보기 후 = 연관 키워드가 포함된 문장 더미.

해결된 부분: 실제 사용자가 더보기를 눌러 읽었을 때 지나치게 SEO 냄새가 나는 문장 더미는 가독성과 신뢰를 떨어뜨릴 수 있으므로, 사람이 읽어도 자연스러운 정보 구조로 정리하는 방향으로 합의.

아직 남은 질문: 현재 약 1,857자를 사용 중이라 약 143자가 남는다. 이 143자를 비워두는 것과, 실제 매장과 연관성이 높은 자연스러운 키워드·정보 문장으로 채우는 것 사이에 검색노출 차이가 존재하는가?
  • 남는 143자 자체가 ‘낭비’인가? 상세설명 글자 수를 많이 채운다는 사실 자체가 SEO 가중치로 작동하는가?
  • 글자 수 자체는 무의미하더라도, 남은 143자에 실제 연관성이 높은 메뉴·상황·지역·시설 정보를 자연스럽게 추가하면 검색 쿼리 매칭 범위가 넓어질 수 있는가?
  • 현재 상단 1·2·3·4 번호형 요약은 더보기 전에 노출되는 영역의 가독성을 높이는가, 아니면 강한 한두 문장보다 오히려 시선을 분산시키는가?
  • ‘울산맛집 / 울산횟집 / 울산북구맛집’ 같은 표현이 상세설명 안에서 반복될 때 어느 수준부터 과최적화·스팸성 문장으로 판단될 가능성이 있는가?
  • 상세설명은 검색노출용 문서와 랜딩페이지용 소개문 중 어느 쪽 비중을 더 높여야 하는가?

대표키워드 75자 — 짧은 단어 2개는 정말 효율적인가?

현재: 활어 / 오션뷰 / 울산오션뷰횟집활어회가족외식 / 울산북구숙성회물회육회코스요리 / 당사동우가항초밥해물탕해산물
  • 15자씩 5칸을 사용할 수 있는데 ‘활어’와 ‘오션뷰’처럼 2~3자만 단독 사용하는 것이 실제로 최적화된 선택인가?
  • 조합형 키워드가 여전히 유효하다면, ‘활어’와 ‘오션뷰’도 각각 15자 가까이 관련 단어를 조합해 쓰는 편이 더 넓은 검색 조합을 확보하는가?
  • 반대로 짧은 단어를 단독으로 두는 것이 네이버의 토큰 인식·정확도 측면에서 더 강한 신호가 되는가?
  • 즉, 한 칸의 글자수를 꽉 채우는 것과 한 칸에 하나의 명확한 핵심개념만 두는 것 중 어떤 방식이 실제 데이터상 우세한가?

찾아오는 길 400자 — ‘교통 정보’인가, 또 하나의 SEO 지면인가?

현재 약 395자 사용. 삼산동·야음동·신정동·옥동·울산대·일산해수욕장·송정동·성남동·강동몽돌해변·정자항·주전몽돌해변에서의 차량 이동시간과 주차·주소·지도앱 검색 방법을 가독성 있게 정리한 상태.
  • 400자를 거의 꽉 채우는 것 자체가 유의미한가? 아니면 ‘찾아오는 길’은 검색노출보다 실제 방문 편의성이 우선인가?
  • 예전처럼 네이버 지도 길찾기에 나오는 도로명·고속도로·몇 km 이동·우회전 같은 세부 경로를 복붙하는 것이 검색노출에 조금이라도 유리한가?
  • 현재처럼 주요 생활권·관광지별 차량 소요시간을 적는 것이 이용자 전환에는 더 유리한가?
  • 삼산동, 송정동, 성남동, 주전몽돌해변 같은 지명이 이 입력란에서 실제 검색 쿼리 매칭에 활용될 수 있는가?
  • ‘울산맛집 / 울산횟집 / 울산북구맛집 / 울산데이트맛집’ 같은 검색형 키워드를 찾아오는 길 상단·하단에 넣는 것이 의미가 있는가, 아니면 이 지면의 목적과 맞지 않아 정보 품질만 떨어뜨리는가?
  • 결국 최적형은 주소·주차 + 주요 생활권별 소요시간 + 근처 랜드마크 중심인지, 아니면 실제 길찾기 경로를 더 구체적으로 복원해야 하는지?

소식 / 업체사진

  • 업체사진의 실질 최고 화질 기준부터 확인: 네이버가 받아주는 최대 가로×세로 픽셀은 몇 px인가? 단순히 파일용량을 20MB에 가깝게 만드는 것이 의미가 있는가, 아니면 네이버 내부 리사이즈/압축 이후 체감화질이 유지되는 적정 픽셀 기준이 따로 있는가?
  • 화질과 SEO를 분리해서 확인: 고해상도 이미지가 고객이 보는 화질에는 도움이 되더라도, 검색노출·SEO·AI 이미지 인식에서 추가 가중치를 주는가?
  • 1·2·3번 업체사진은 별도 최우선 슬롯으로 볼 것: 해우 플레이스에서 ‘더보기’를 누르기 전 바로 보이는 첫 번째·두 번째·세 번째 사진은 CTR 이후 몰입을 좌우하므로, 어떤 역할로 각각 설계해야 하는가? 예: ① 12계단 대표메뉴+오션뷰 ② 오션뷰/외관 ③ 단체석 또는 해물탕 액션.
  • 업체사진 순서가 네이버 노출 화면에서 항상 고정되는지, 노출 지면·기기·광고 여부에 따라 일부 섞이거나 다른 이미지가 끼어드는지 확인할 필요가 있는가?
  • 4~120번의 존재가치: 실제로 ‘더보기’를 눌러 사진을 깊게 보는 소수 고객을 위해 120장까지 채우는 것이 전환 측면에서 의미가 있는가?
  • SEO/정보충실성 측면의 4~120번: 이용자가 거의 보지 않더라도 사진 수·최신성·카테고리 다양성이 네이버의 업체 정보 충실성 또는 인기도 판단에 유의미한 신호가 되는가?
